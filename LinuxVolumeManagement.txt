go into root use with sudo su.
then run into logical volume manager of linux.
 
command:

lvm: enter into logical volume manager.
 
till now we dont have physical volumes.
lets create them.

pvcreate /dev/xvdf /dev/xvdg /dev/xvdh : this create three volumn from blocks
see them with pvs.

lets make group volume name name them tws-volume
vgcreate tws-vg /dev/xvdf /dev/xvdg : this will create group volume with combining two volumes.
see them with vgs

now lets creata a logical volume with the volume group.
lvcreate -L 10G -n tws_lv tws_vg :  this will create a logical volume of 10Gb  name is tws_lv from tws_vg(volume group).
see them with pvdisplay and lvdisplay and vgdisplay.

lets do mounting?

now first we will create a folder strcuture with
mkdir /mnt/tws_lv_mount
now we will format tha logical volume
mkfs.ext4 /dev/tws_vg/tws_lv

not mount to location:
mount /dev/tws_vg/tws_lv /mnt/tws_lv_mount

check it with df -h
 
umount is used to unmount.
again you can mount it.
